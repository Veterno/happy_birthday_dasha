# Даша — готическое поздравление с днём рождения

React + TypeScript + Vite, без UI-фреймворка: вся визуальная система собрана в CSS.

## Страницы

- `/` — поздравление
- `/cards` — 6 вращающихся 3D-карточек; у каждой можно загрузить фотографию и переворачивать карту кликом
- `/wishes` — отдельная страница с пожеланиями
- `/author` — автор, Telegram, GitHub, Valorant и загрузка фото автора

## Запуск

```bash
npm install
npm run dev
```

Для production-сборки:

```bash
npm run build
```

Фото карточек сохраняются через `sessionStorage` в виде data URL и живут в рамках текущей вкладки браузера.
